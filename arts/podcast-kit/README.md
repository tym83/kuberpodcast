# Kubernetes Community Podcast — графический кит

Вся графика подкаста (заставки и картинки для площадок) рисуется кодом на HTML5 canvas.
Никаких внешних шрифтов, картинок и библиотек: буквы, облака, серверы и какашка — это наборы
координат, которые обводятся дрожащей линией. Поэтому пакет полностью воспроизводим:
одна команда — и все файлы пересобираются заново.

## Что нужно на машине

- **Node.js 18+**
- **ffmpeg** (`brew install ffmpeg` / `apt install ffmpeg`) — только для сборки видео
- браузер Chromium ставится сам вместе с Playwright

```bash
npm install
npx playwright install chromium   # если Chromium ещё не стоит
```

## Команды

```bash
npm run images          # все картинки → out/images/   (~40 секунд)
npm run video           # основная заставка 17 сек → out/kids.mp4   (~4 минуты)
npm run video:noir      # нуарная версия
npm run video:garage    # гаражная версия
npm run video:postpunk  # пост-панк версия
npm run smoke           # 20 кадров вместо 510 — быстро проверить, что всё живо
```

Точечно:

```bash
node tools/render-images.js apple_podcasts_3000        # один файл
node tools/render-video.js kids --frames 30            # короткий тест
node tools/render-video.js styles noir --crf 22        # сильнее сжать
```

## Что где лежит

```
src/scene-kids.html     заставка 17 сек: 10 сек летающих предметов + 7 сек титров
src/scene-styles.html   та же заставка в трёх стилях: noir / garage / postpunk
src/pack.html           статичная графика: обложки, аватарки, шапки, сторис
tools/render-video.js   покадровый рендер сцены + сборка mp4 через ffmpeg
tools/render-images.js  рендер картинок; список форматов — прямо в начале файла
out/                    результат (в git не попадает)
```

Каждый `src/*.html` — самодостаточный файл: примитивы рисования, объекты, алфавит и макеты
внутри него. Его можно просто открыть в браузере и увидеть первый кадр.

## Как поменять частое

**Название и подписи.** Ищите вызовы `drawText(...)`. В `src/pack.html` они собраны в
функции `lockup()` и в макетах внутри `LAYOUT`. В `src/scene-kids.html` — в `drawOutro()`
(титры) и `drawBoard()` (надпись мелом).

**Цвета.** В `src/pack.html` сверху: `INK` (контур) и `PAPER` (фон), остальные цвета лежат
в самих объектах (`oBox`, `oServer` и т.д.). Фирменная палитра:

```
бумага    #FFF7E8      контур     #33241B      доска     #2F4A40
синий     #4D96FF      жёлтый     #FFD447      оранж.    #FF7A45
красный   #FF5A5F      зелёный    #6DD47E      фиолет.   #B292FF
розовый   #FF8CC6
```

**Новый формат картинки.** Допишите строку в `ASSETS` (`tools/render-images.js`) и, если нужен
новый макет, функцию в объекте `LAYOUT` (`src/pack.html`).

**Состав и траектории летающих предметов** — массив `FLY` в сценах. Поля описаны в CLAUDE.md.

**Длительность видео.** В сценах: `DUR` — часть с предметами, `OUTRO` — титры. Общее число
кадров считается как `FPS*(DUR+OUTRO)`; менять `TOTAL` отдельно не нужно.

## Подробности для доработки

Смотрите `CLAUDE.md` — там устройство рисования, система координат, как добавить букву в
алфавит, как устроены темы и тайминг титров. Файл написан так, чтобы Claude Code мог
подхватить проект без дополнительных объяснений.
