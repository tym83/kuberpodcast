# Заметки для Claude Code

Репозиторий обслуживает подкаст про Kubernetes и инфраструктуру. Здесь три
независимых конвейера — новостной дайджест, страницы выпусков и графика.
Ниже то, что нужно знать до того, как что-то запускать или менять.
Человеческое описание — в `README.md`.

## Что где лежит

| Папка | Что это |
|---|---|
| `digestbot/` | Библиотека дайджеста: сбор, фильтры, скоринг, отрисовка. Плюс `episode.py` — расшифровка выпусков |
| `scripts/` | Точки входа. Всё, что запускается руками или по расписанию |
| `sources/` | Конфигурация обоих конвейеров. **Правится здесь, а не в коде** |
| `digest/` | Опубликованные выпуски дайджеста. Только результат работы конвейера |
| `episodes/<N>/` | Расшифровка, субтитры и страница выпуска для YouTube |
| `arts/` | Заставки, обложки и генератор графики (`podcast-kit`, отдельный Node-проект со своим `CLAUDE.md`) |
| `state/` | Память между запусками: `emitted.sqlite`, `feed_health.json` |
| `data/` | Сырые выгрузки и кэш текстов. В git не попадает |

## Команды

```bash
# дайджест: сбор → сборка выпуска
./.venv/bin/python scripts/collect_raw.py --days 7 --out data/raw.json
./.venv/bin/python scripts/build_digest.py --raw data/raw.json --outdir digest

# то же целиком, с коммитом и PR
./scripts/run_local.sh                 # боевой прогон
./scripts/run_local.sh --dry-run       # пишет в ~/.local/state/kuberpodcast/dry-run

# выпуск подкаста из записи
./.venv/bin/python scripts/make_episode.py запись.mp4 --number 2

# проверка конфигов (её же гоняет CI)
./.venv/bin/python scripts/check_sources.py
```

Виртуальное окружение — `.venv`, зависимости в `requirements.txt`.
Для выпусков нужны `ffmpeg` и `whisper-cli` (`brew install ffmpeg whisper-cpp`).

## Правила, которые легко нарушить

**Не писать тестовый вывод в `digest/` и `episodes/`.** Там лежат
опубликованные материалы. Пробный прогон, записавший туда результат с окном в
один день, однажды уже затёр готовый выпуск — молча, заметили только при
чтении диффа. Для проб есть `--outdir` и `--dry-run`.

**`state/` отслеживается git намеренно.** Раннер каждую неделю новый, и
межнедельная дедупликация работает, только если `emitted.sqlite` едет вместе с
репозиторием. Не добавлять в `.gitignore`.

**Порог релевантности считается по словарю в `sources/blocklists.yaml`.**
Слова нет в словаре — материал молча уходит в офтопик. Так едва не потерялась
главная новость недели: в словаре не было ни VMware, ни Broadcom, ни
licensing. Если пользователь говорит «а почему тут нет X» — сначала проверять
словарь, потом всё остальное. Файл `digest/<дата>-rejected.md` пишется ровно
для этого.

**Секции с смыслом не добиваются остатками.** «Инциденты», «Безопасность»,
«Экосистема», «Исследования» наполняются только тем, что действительно ими
является. Иначе заголовок секции начинает врать.

**Главы YouTube проверяются кодом.** Первая ровно в `0:00`, порядок по
возрастанию, минимальный интервал. Список, нарушающий хоть одно правило,
YouTube не показывает вообще и ничего об этом не сообщает.

## Конфигурация

| Файл | За что отвечает |
|---|---|
| `sources/feeds.yaml` | 476 RSS-лент: id, url, язык, категория, вес 1–5 |
| `sources/community.yaml` | Reddit, Hacker News, Lobsters, dev.to, Juejin |
| `sources/releases.yaml` | GitHub-репозитории и порог новостности `min_bump` для каждого |
| `sources/signals.yaml` | CVE-фиды, статус-страницы, майнинг ньюслеттеров, CNCF TOC |
| `sources/bridges.yaml` | Telegram, Bluesky, Google Groups — источники без RSS |
| `sources/blocklists.yaml` | Фильтры шума и словарь релевантности |
| `sources/editorial.yaml` | Квоты секций, формула скоринга, правила свежести |
| `sources/episode.yaml` | Модель Whisper, словарь ошибок распознавания, правила разметки глав |

Обоснование правил отбора — `sources/review-5-editorial.md`, спецификация на
1167 строк, по которой написан скоринг.

## Ключи и доступы

`ANTHROPIC_API_KEY` необязателен: SDK читает профиль, созданный
`ant auth login`, из `~/.config/anthropic/`. Проверять наличие учётки надо
обоими способами — код это уже делает, но при правке легко сломать.

Секреты локального запуска — `~/.config/kuberpodcast/env`, формат `KEY=value`.
`run_local.sh` читает его сам.

Без учётки или без денег на балансе конвейер не падает: подставляет
детерминированные комментарии с пометкой, что они автоматические.

## Известные ограничения источников

- **Reddit** лимитирует по IP, а не блокирует. Публичный `.rss` не отдаёт ни
  рейтинга, ни числа комментариев — вовлечённость считается по позиции в
  недельном топе. OAuth снимает и лимит, и слепоту.
- **С раннеров GitHub** Reddit почти не отвечает: адреса дата-центров душатся
  жёстче. Поэтому основной прогон локальный, а Actions — резерв.
- **Не автоматизируется:** openEuler (WAF), CSDN, SegmentFault, публичный
  RSSHub, WeChat-каналы китайских техкоманд.
- **Whisper** стабильно путает названия: Talos → «Сталос», Argo CD →
  «Margo CD». Словарь в `sources/episode.yaml`. Ещё он дописывает выдуманные
  титры на финальной тишине — отбрасываются только в хвосте, потому что те же
  слова в середине были бы настоящей речью.

## Расписание

Дайджест собирается по пятницам: локально в 09:00 через launchd
(`contrib/io.kuberpodcast.digest.plist`), а `.github/workflows/weekly-digest.yml`
в 15:00 UTC — резерв, который выходит сразу, если выпуск за день уже есть.

## Стоимость

Дайджест — около `$1.14` за выпуск (13 запросов, ~76k входных токенов).
Страница выпуска — около `$0.30`. Расшифровка бесплатна, считается локально.
Цифры печатаются в конце прогона, гадать не нужно.
